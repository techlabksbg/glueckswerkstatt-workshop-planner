# Aufgaben zu CSV-Dateien

  * Öffnen Sie die Datei [fehler.csv](fehler.csv) mit einer Tabellenkalkulation (z.B. Libreoffice Calc, oder Excel).
    * Überprüfen Sie, ob die Tabelle auch korrekt dargestellt wird.
  * Schliessen Sie die Datei wieder
  * Studieren Sie die Datei [fehlerfinden.py](fehlerfinden.py) und lösen Sie darin gestellte Aufgabe.
    * **Achtung**: Damit das Programm die benötigte Datei fehler.csv auch einlesen kann, muss es im Verzeichnis '''csv-uebungen/csv''' ausgeführt werden.
    * Wechseln Sie dazu ins entsprechende Verzeichnis in der VS-Code Kommandozeile (die sich öffnet, wenn Sie das Programm ausführen).
  * Erstellen Sie in einer Tabellenkalkulation selbst eine CSV-Datei analog zur Datei fehler.csv (mit anderen x-Werten, und gleichen, entsprechenden Spalten) und testen Sie das von Ihnen erstellte Programm.
